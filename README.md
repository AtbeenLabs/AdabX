# AdabX 2.0

**همراه هوشمند یادگیری ادبیات فارسی**

AdabX یک محیط یادگیری فارسی و راست‌چین برای فارسی هشتم و آشنایی با المپیاد ادبی است. نسخهٔ ۲ با معماری React و TypeScript بازطراحی شده است.

## امکانات
- صفحهٔ معرفی مینیمال و واکنش‌گرا
- کتابخانهٔ ۱۷ درس فارسی هشتم با جست‌وجو و دسته‌بندی
- راهنمای درس، نکته‌های مرور و ثبت وضعیت مطالعه
- آزمون‌ساز با انتخاب موضوع، سطح، تعداد پرسش و زمان
- تصحیح پاسخ، توضیح آموزشی و گزارش آزمون
- دستیار داخلی آفلاین برای چند مفهوم پایه
- امکان اتصال امن دستیار به API از طریق Cloudflare Worker
- آرشیو دفترچهٔ مرحلهٔ اول المپیاد ادبی ۱۴۰۱ و نقشهٔ موضوعی
- گزارش پیشرفت، تاریخچهٔ آزمون و خروجی/بازیابی پشتیبان
- PWA قابل نصب و زیرساخت کش آفلاین
- ساخت و انتشار خودکار با GitHub Actions

## اجرا
```bash
npm install
npm run dev
npm run build
```

## هوش مصنوعی آنلاین
دستیار داخلی بدون سرویس بیرونی هم کار می‌کند، اما پاسخ‌های آن محدود و مبتنی بر راهنمای ثابت است. برای فعال‌شدن مدل زبانی آنلاین:
1. پوشهٔ `worker` را به‌عنوان Cloudflare Worker منتشر کن.
2. secret با نام `AI_API_KEY` را در تنظیمات Worker ثبت کن.
3. مقدار `ALLOWED_ORIGIN` را با دامنهٔ سایت هماهنگ کن.
4. در زمان build مقدار `VITE_AI_ENDPOINT` را برابر نشانی Worker قرار بده.

کلید API نباید در کد مرورگر یا مخزن عمومی قرار بگیرد.

## داده و حریم خصوصی
- حساب کاربری لازم نیست.
- پیشرفت در مرورگر و روی همان دستگاه ذخیره می‌شود.
- از بخش «پیشرفت من» می‌توان نسخهٔ پشتیبان JSON گرفت یا آن را بازیابی کرد.
- پاک‌کردن داده‌های مرورگر ممکن است اطلاعات محلی را از بین ببرد.

## شفافیت محتوا
- پرسش‌های بانک فعلی تألیفی‌اند و سؤال رسمی المپیاد معرفی نمی‌شوند.
- یادداشت‌های دو درس نخست محتوای آموزشی مشخص دارند؛ بسیاری از درس‌های دیگر فعلاً راهنمای مطالعه‌اند و جای متن کامل کتاب را نمی‌گیرند.
- نقشهٔ موضوعی المپیاد راهنمای مطالعه است. پاسخ‌نامهٔ رسمی تأییدشده در این نسخه ارائه نشده است.
- PDF دفترچه از میزبان اصلی IRYSC بارگیری می‌شود و در دسترس‌بودن آن به میزبان وابسته است.
