# AdabX

آزمایشگاه یادگیری ادبیات فارسی پایهٔ هشتم.

AdabX یک وب‌اپلیکیشن فارسی و راست‌چین برای مرور درس‌ها، تمرین مفاهیم زبانی و ادبی، شرکت در آزمون‌های تألیفی و دسترسی به منابع المپیاد ادبی است.

## امکانات فعلی

- صفحهٔ خانه و داشبورد یادگیری
- فهرست ۱۷ درس کتاب فارسی هشتم، مطابق فهرست کتاب چاپ سیزدهم ۱۴۰۵
- یادداشت‌های آموزشی و نکته‌های مرور
- تمرین تعاملی با بازخورد پاسخ
- آزمون جامع ۱۲ پرسشی
- آرشیو موضوعی دفترچهٔ مرحلهٔ اول سی‌وششمین المپیاد ادبی ۱۴۰۱ با لینک PDF اصلی
- ذخیرهٔ پیشرفت روی مرورگر با `localStorage`
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرای محلی

فایل `index.html` را در مرورگر باز کن. برای توسعه می‌توانی از افزونهٔ Live Server یا یک سرور محلی ساده استفاده کنی.

## شفافیت محتوا

- سؤال‌های تمرینی داخل سایت **تألیفی** هستند و سؤال رسمی آزمون یا المپیاد معرفی نمی‌شوند.
- فهرست موضوع‌های المپیاد فقط راهنمای موضوعی است؛ متن کامل سؤال‌ها و گزینه‌ها در PDF منبع اصلی قرار دارد.
- پاسخ‌نامهٔ تأییدشدهٔ دفترچهٔ المپیاد هنوز در سایت ارائه نشده است.
- توضیح‌های بعضی درس‌ها فعلاً راهنمای مطالعه بر اساس عنوان و ساختار کتاب‌اند؛ برای متن کامل و جزئیات هر درس باید به کتاب درسی مراجعه کرد.

## منابع

- کتاب فارسی پایهٔ هشتم، چاپ سیزدهم ۱۴۰۵، وزارت آموزش و پرورش؛ فهرست درس‌ها و مباحث آغازین.
